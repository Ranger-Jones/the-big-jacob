# Übersetzungen (i18n)

Die App ist zweisprachig (Deutsch / Englisch). **Der deutsche Text ist der Schlüssel.**

## Im Code

- Client-Komponenten: `const t = useT();` aus `@/lib/i18n/client` → `t('Passen')`
- Server-Komponenten, `generateMetadata`, Server Actions: `const t = await getT();` aus `@/lib/i18n/server`
- Platzhalter in geschweiften Klammern: `t('{name} ist dran', { name })` – niemals Template-Strings in den Schlüssel bauen.
- Zahlen/Plural: getrennte Schlüssel, z. B. `count === 1 ? t('1 Karte') : t('{count} Karten', { count })`.
- Datum/Zahlen: `useIntlLocale()` bzw. `intlLocale(locale)` statt fest `'de-DE'`.
- Fehlertexte vom Server (`fail('…')`) bleiben deutsch und werden beim Anzeigen übersetzt: `toast.error(t(res.error))`.
- Reine Hilfsfunktionen (z. B. `describeLog`) bekommen `t: T` als Parameter (Default: Identität).
- Nicht übersetzen: Markennamen („Der Große Jakob“), Benutzernamen, Raum-Codes, Emojis, CSS-Klassen, Daten-IDs.
